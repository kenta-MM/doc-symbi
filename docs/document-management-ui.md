# ドキュメント管理UIの再設計

## 画面と責務

React、既存のDocumentSession、TipTapエディタを継続利用する。追加依存はない。

- 一覧: `DocumentCatalog`がタイトル／本文、ルート相対パス、実フォルダ、複数タグのうち選択したタグ、種類の条件をANDで適用する。更新日時・作成日時・タイトルで並べ替える。
- ナビゲーション: `FolderNavigation`が実ディレクトリ階層を表示し、展開・折りたたみ、検索／タグ欄への移動を提供する。
- 閲覧・編集: 既存の`EditorPane`、`BlockToolbar`、画像・表・履歴・インポート／エクスポートを再利用。左にアウトライン、右に`DocumentProperties`を配置する。右ペインは開閉可能。
- 作成: `NewDocument`が名前・種類・保存先・タグ・ステータスを受け付け、最初の保存後に編集する。保存失敗時は下書きを保持して編集画面で再試行できる。
- 画面状態: 文書なしは一覧、作成フラグは作成画面、開いた文書があれば閲覧・編集。ルートURLでは一覧を表示し、従来の`#article=<UUID>`リンクは継続対応する。
- 未保存の確認: 既存のセッション世代管理・保存キュー・ナビゲーションガードを再利用する。メタデータもセッション経由で変更するためCtrl+Sと移動確認の対象になる。

## 保存互換性

`.docsymbi.json`の既存スキーマと本文表現を変更しない。文書の`metadata`に`type`、文字列配列`tags`、`status`を保存する。文書IDは従来のトップレベル`id`を使用する。種類・タグ・ステータスを未設定の文書は表示時に既定値を補い、読み込みだけではファイルを書き換えない。その他の任意メタデータは保持する。

所属フォルダはファイル探索結果の`folderPath`として一覧用データに付与し、文書JSONには書き込まない。ファイル名・パスとUUIDを分離し、外部移動・改名後も同一IDを探索する。更新時・削除時は探索された実ディレクトリのハンドルを使う。新規作成はセッションに渡された保存先パスに保存する。

ファイル全体のハッシュによる既存の競合検知、同一originの書き込みロック、ファイルサイズ検証を維持する。外部アプリと厳密な排他はできない。ファイル探索中の不正ファイル・重複IDは従来どおりエラーとして報告し、黙って除去しない。

保存先未接続時は既存IndexedDBリポジトリを利用する。接続後は実フォルダが保存先となり、ブラウザ内のデータは「ブラウザ内の記事をコピー」で明示的に複製する。コピー元は削除しない。保存先ハンドルの記憶・権限再要求・失敗通知は既存機構を維持する。

## フォルダ操作

フォルダツリーは空フォルダも含む。検索は標準で子孫を含み、完全なルート相対パスを使用して同名のフォルダを区別する。パスの親遡及・絶対パス・不正な区切りは拒否する。

アプリ内で実行できる操作は作成・空フォルダの改名・空フォルダの削除。削除にはrecursiveを使用せず、DocSymbi以外のファイルや操作中に追加されたファイルも保護する。内容のあるフォルダの移動・改名はOSで行い、一覧の再読み込みで反映する。全内容の複写と削除による疑似移動は実装しない。

再読み込み・再接続は一覧を更新し、開いている編集内容を上書きしない。外部本文の変更は一覧へ戻って開き直す。保存前に外部更新を検出した場合は既存の競合エラーとなる。

## 段階的な拡張範囲

- テンプレートは空の文書のみ。定義レジストリを分離し、設計書の雛形は今後追加可能。
- 関連文書・ゴミ箱は既存機能がないため追加していない。
- 内容のあるフォルダのアプリ内移動・改名、文書の保存先移動、フォルダの自動監視は将来の拡張。
- 本文検索はローカルの読み込み時に生成する。大量文書向けの永続検索インデックス・ページ分割は未実装。
- ブラウザの実OSフォルダ許可操作は手動確認対象。自動試験はOPFSの実ファイル操作を用い、OSピッカーのみ代替する。

## 検証

単体テストでは旧メタデータの既定値、本文抽出、子孫判定、不正パスを確認する。追加した統合テストでは実ディレクトリへの保存、外部移動・改名、移動後の保存・削除、非空フォルダの保護を確認する。

追加E2Eでは一覧起動、実フォルダ作成、指定先への新規文書保存、複合検索、パンくず、メタデータ保存、右ペイン開閉、ツリー折りたたみをオンライン／オフラインで確認する。既存の画像・表・リンク・履歴・編集・保存・取り出し・復元テストも新しい画面遷移に合わせて継続する。

性能計測は既存の未コミット測定結果を保持するため`validation/document-ui-performance.*`へ出力する。
