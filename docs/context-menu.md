# フォルダ・ファイルの操作

別のフォルダ行をクリックした場合は選択だけを変更します。選択中の同じフォルダ行をクリックすると展開・折りたたみを切り替えます。ファイルのクリックで文書を開きます。

- フォルダの右クリック: フォルダを作成、ドキュメントを作成、フォルダ名を変更、フォルダを削除。作成先は対象フォルダ直下です。
- ファイルの右クリック: ファイル名を変更、ファイルを削除。
- フォルダ見出し横の「⋯」→「更新」: 保存先を再走査して階層・文書一覧を更新します。
- ツリーの空白: 選択フォルダに作成。一覧の空白: 表示フォルダに作成。横断検索で作成先が決定できない場合は選択画面を開きます。
- Shift+F10 / メニューキーでも操作できます。メニュー外クリック・Esc・項目選択で閉じます。

名前変更後は実ファイル名と文書名を更新し、ID・本文・メタデータを保持します。フォルダ名変更は配下をコピー・照合してから元フォルダを削除します。コピー失敗時は元データを残します。元フォルダの削除に失敗した場合はコピーを残し、OSでの確認を案内します。

削除は確認画面を表示します。フォルダ削除は配下の全ファイル（DocSymbi以外のファイルも含む）が対象です。保存先ルート自体の名前変更・削除はできません。

保存先未設定では実フォルダを作成しません。文書は既存のブラウザ内保存を利用します。接続済みの保存先にアクセスできない場合は再接続を案内し、ブラウザ内保存には切り替えません。
