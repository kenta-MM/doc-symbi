# DocSymbi

構造化ドキュメントをローカルで編集・管理するデスクトップWebアプリです。
段落・見出し・リスト・コード・表・画像・クイズ、フォルダ管理、テンプレート、
文書とフォルダのロック、AIによる文書の作成・修正案に対応しています。

このREADMEは現在の画面と実装を説明します。実機・利用者評価を含む最終受け入れは未完了です。
計画は [tasks.md](specs/001-structured-editor-mvp/tasks.md)、受け入れ記録は
[validation](specs/001-structured-editor-mvp/validation/acceptance.md) を参照してください。

## 起動

Node.js 22系（22.12以上、23未満）とnpmを使用します。依存関係はlockfileで固定しています。
このワークスペースに導入済みのNodeを使う場合はPowerShellで次を実行します。

```powershell
$env:PATH = "$PWD\.tools\node-v22.23.4-win-x64;$env:PATH"
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.tools\playwright"
npm ci
npx playwright install chromium
npm run dev
```

VS Codeでこのフォルダを開き、F5の「DocSymbi: F5で起動」を選ぶと、開発サーバーと
Chromeを起動して http://localhost:5173 を開きます。停止はサーバーのデバッグでShift+F5です。
WindowsのF5構成は上記のローカルNodeを使用します。

本番ビルドの確認には次を使用します。

```powershell
npm run build
npm run preview
```

previewは http://localhost:4173 です。5173と4173は別の保存設定を持つため、
それぞれで保存フォルダを選択してください。同じ実フォルダを選ぶことはできます。

## 文書とフォルダ

- ルートURLでは文書一覧を表示します。左のフォルダツリーから文書を開けます。
- 「新規作成」で文書名・種類・保存先・タグ・ステータス・テンプレートを指定します。
  作成時に保存し、その後の編集は「保存」または既定のCtrl+Sで明示保存します。
- 既存文書はビューモード、新規文書は編集モードで開きます。「編集」「編集を終了」で切り替えます。
  モード切り替えだけでは保存しません。未保存の状態で移動すると保存・破棄・キャンセルを選べます。
- 一覧でタイトル・本文を検索し、種類・タグ・フォルダで絞り込めます。
  検索語末尾の `/` は保存先ルートからのフォルダパスとして扱います。
- フォルダ・文書の右クリックメニューで作成、名前変更、削除、ロックを操作できます。
  文書にはタグを追加できます。フォルダの名前変更・削除は配下の内容も対象です。
  保存先ルート自体は名前変更・削除できません。
- フォルダツリーの文書を別のフォルダへドラッグすると移動できます。関連画像も一緒に移動します。
- 「文書情報」から種類・タグ・ステータスを確認・編集できます。左のアウトラインから見出しへ移動できます。
- 文書のURLは `#article=<文書ID>` です。同じアプリURLと保存先で開けます。
  タイトル変更後もIDは変わりません。URLだけで文書が公開されることはありません。

## 保存先とバックアップ

フォルダ欄の同期アイコン（「フォルダを同期・再接続」）で保存先へ接続します。
初回はフォルダ選択、接続済みの場合は再接続と一覧の更新を行います。
右クリックメニューの「同期・再接続」も利用できます。
実フォルダ保存はデスクトップ版Chrome・Edgeを対象とします。

未接続時の文書はブラウザ内のIndexedDBに保存します。フォルダに接続しても、
既存のブラウザ内文書は自動では移行しません。移行処理は実装されていますが、
現在の画面には移行ボタンを配置していません。

画像を含む文書は、本文JSON・説明JSON・画像ファイルを分離して保存します。

```text
保存先/
├─ 文書名--識別子.docsymbi.json
└─ _docsymbi-assets/
   └─ 文書ID/
      └─ 画像ブロックID/
         ├─ 内容識別子.json
         └─ 内容識別子.png  （jpg / webp / svgにも対応）
```

本文から説明JSONを相対パスで参照し、説明JSONから画像本体を参照します。
画像と説明は文書専用で、他文書と共有しません。アプリ内の移動・削除では関連ファイルも扱います。
OS上でバックアップ・移動する場合は、本文JSONと対応する素材フォルダを同じ相対配置で扱ってください。

- 保存先のフォルダハンドルをIndexedDBに記憶します。再起動後はアクセス許可が必要な場合があります。
- 「保存済み」は現在の保存先への書き込み完了です。未保存の変更を強制終了後に復旧する機能はありません。
- 外部変更を検出した場合は上書きを拒否します。説明JSONや画像の変更も競合検知の対象です。
- 外部でファイルを変更したら同期し、未保存内容の扱いを選んで文書を開き直してください。
  編集中の本文を同期だけで自動上書きすることはありません。
- 欠落した画像や不正な参照を黙って除去して保存することはありません。関連ファイルのエラーを表示します。
- 持ち運び用の自己完結JSONの読み込み・取り出し処理は実装されていますが、現在の画面には
  `FileTransfer` の操作ボタンを配置していません。通常のバックアップには上記のファイル一式を使用してください。

形式仕様は [document-format.md](docs/document-format.md)、分離保存と移行の詳細は
[image-storage.md](docs/image-storage.md) を参照してください。

## 画像

PNG・JPEG・WebP・SVGを添付できます。「画像を添付」でファイルを選び、図題・代替テキスト・
目的・要約などを入力して「画像情報を適用」を押します。本文へのドロップ、クリップボードからの貼り付けにも対応します。
再編集は画像を右クリックして「画像の詳細設定」を選び、文書の「保存」で保持します。
構成要素・関係・読み順・前提・出典も説明JSONに保存できます。

画像1枚あたり・画像合計のバイト容量にアプリ独自の上限は設けません。
従来の1枚3 MiB制限と、移動時の画像読み込み10 MiB制限は解除しています。
実際に扱える容量はブラウザのメモリー・保存領域に依存します。以下の上限は残っています。

- 画像寸法：縦横それぞれ20,000ピクセル。
- 本文・説明情報・metadata：合計10 MiB。画像本体は含みません。
- 本文100万文字、要素1万、リスト深さ32。
- 持ち運び用の自己完結JSON：画像込み256 MiB。

画像を含むフォルダ保存はschemaVersion 5です。従来の埋め込み形式v1〜v4も読み込め、
次回のフォルダ保存で分離形式に変換します。閲覧だけでは元ファイルを書き換えません。

## 編集操作

- 選択範囲がある場合はその範囲、なければカーソル位置に操作を適用します。
- 段落先頭で `# `〜`###### `、`- `、`1. ` を直接入力すると見出しやリストへ変換します。
  見出し内の `1. ` や `- ` はリストへ変換せず、見出しを維持します。
  「記号の自動変換」で切り替えられます。変換直後のBackspaceで記号を復元できます。
- 空の段落で `/` を入力すると表・クイズ・コードブロック・見出しのメニューが開きます。
  `/ta`、`/qu`、`/code`、`/heading` や日本語で絞り込み、上下キーで選択し、EnterまたはTabで確定します。
  Escで入力を残して閉じます。
- 見出し末尾のEnterで通常の段落を作成します。
- 段落先頭でバッククォートを2回入力するとコードブロックへ変換します。
  コード内のEnterは改行、Ctrl+Enterはコードの後に段落を追加します。
- 「インラインコードブロック」または半角ダブルクォート2回の直接入力で、インラインコードを切り替えます。
- 太字は既定のCtrl+B、取り消しはCtrl+Z、やり直しはCtrl+Shift+Zです。Ctrl+Yにも対応しています。
- 選択せずにCtrl+Xを押すと、カーソルのある行を切り取ります。選択中は選択範囲を切り取ります。
- 選択文字の右クリックからリンクを挿入できます。閲覧モードでリンクを開けます。
- 表ではTab／Shift+Tabでセル移動、Enterでセル内改行、Ctrl+Enterで表の後に段落を追加します。
  右クリックで行・列の追加・削除、表のコピー・削除ができます。コピーした表は本文へ貼り付けられます。

## ロックと設定

文書上部または文書・フォルダの右クリックメニューから「ロック」「ロックを解除」を操作します。
未保存の変更がある場合は先に保存してください。フォルダのロックは配下にも適用します。
ロックされた文書は読み取り専用となり、編集・保存・削除・移動を拒否します。
ロックされたフォルダへの作成や、ロック対象を含む親フォルダの削除・名前変更も拒否します。
AIにはロック操作を公開せず、ロックされた文書への変更案の適用も拒否します。

ロックは本文のmetadataと別に、このブラウザの保存先ごとに保持します。
外部アプリや別ブラウザへのファイルシステム権限を設定する機能ではありません。

「設定」→「表示・ショートカット」でダークモードと、保存・取り消し・やり直し・太字・見出しの
キー割り当てを変更できます。入力欄でCtrl（Macは⌘）またはAltを含むキーを押し、「保存」で反映します。
重複したキーの割り当ては拒否します。「既定のキーに戻す」で初期値へ戻せます。
設定はこのブラウザに保存します。

## テンプレートとクイズ

文書上部の「テンプレートとして保存」で現在の本文からひな形を保存できます。
「新規作成」の「使用するテンプレート」で選ぶと、本文・画像・表・クイズを引き継いだ別文書を作成します。
元のひな形は変更せず、画像も新しい文書専用に保存します。テンプレートも通常の文書と同様に編集・削除できます。

「クイズを追加」で問題文・2〜10個の選択肢・正解・解説を設定し、最大100問をまとめられます。
回答形式はラジオボタンの単一選択、チェックボックスの複数選択から選べます。
複数選択は、選択した項目が正解の集合と一致した場合に正解になります。
閲覧中も回答・問題間の移動が可能です。回答履歴は保存せず、再読み込みや問題変更でリセットします。

編集モードでは「クイズを編集」で変更し、「クイズを削除」ボタンまたは右クリックメニューで削除できます。
削除は取り消し可能です。クイズを含む本文モデルはv4、画像も含む場合のフォルダ保存はv5です。

## AIチャット

Codex CLIでログインし、ローカルサーバーを起動して「AIチャット」を開きます。
「設定」→「AI」で利用するAIを選択し、チャット欄で接続とモデルを選びます。Claude連携は準備中です。

AIは文書の新規作成・既存文書の修正案を返します。案を確認して「文書を作成」「変更を適用」を押すと
未保存の編集へ反映します。最後に通常の「保存」が必要です。依頼後に文書や保存先が変わった場合、古い案は適用できません。
AIの作成先は既存のフォルダのみです。画像・クイズの新規生成は対象外です。

通常の文書保存はローカルで行います。AIチャット送信時は文書のテキスト・構造・画像の説明情報・フォルダ情報を
AIへ共有します。画像本体は送信せず、画像の自動解析は行いません。
接続方法は [AI接続メモ](docs/ai-integration.md)、適用の仕組みは
[AI文書編集](docs/ai-document-editing.md) を参照してください。

## オフラインと検証

production buildはWorkbox Service Workerでアプリ資産をキャッシュします。
オンラインで準備した同じorigin・ブラウザプロファイルでは、サーバー停止後もローカル編集を利用できます。
開発サーバーはService Workerを登録しません。AIチャットにはローカルサーバーとAIへの接続が必要です。
現在の画面にはオフライン準備状況・更新適用の専用UIを配置していません。

```powershell
npm run typecheck
npm run lint
npm run test:unit
npm run test:contract
npm run build
npm run test:integration
npm run test:e2e
npm run test:performance
```

Playwrightは4173を専有するため、手動previewを終了してから実行してください。
テストは独立した `.test-build` とテスト用harnessを使用し、通常の `dist` にharnessは含めません。
E2Eはオンラインと準備済みオフラインの両方を実行します。
ファイル操作試験は隔離したOPFSでフォルダ選択を代替するため、実フォルダのOS権限確認は別途必要です。
テスト結果・ブラウザ・依存・ビルド成果物はGit対象外です。

画像の分離保存・容量制限解除の対象テスト：

```powershell
npm run test:integration -- external-images.spec.ts --workers=1
npm run test:e2e -- large-image.spec.ts --workers=1
```

作例は [Hyperscale文書](docs/azure-sql-hyperscale.docsymbi.json) と
[画像・意味データ](docs/hyperscale-figures/) にあります。
`node scripts/create-hyperscale-figures.mjs` で図と意味データを再生成できます。
